Tools developed

CoPaLink

CoPaLink is a tool designed to automatically extract the names of bioinformatics tools mentioned in a scientific article describing a Nextflow workflow, as well as in the executable source code of the workflow. A linking step between the bioinformatics tool names from both sources is then performed.

GitLab repository: https://gitlab.liris.cnrs.fr/sharefair/copalink

Corpora

BioToFlow

BioToFlow is an annotated corpus describing bioinformatics workflows in English publications. This corpus is composed of 52 articles (26 articles related to Nextflow workflows and 26 on Snakemake workflows, randomly selected from PubMed) with a total of 78,419 tokens, 27,786 annotated tokens with 16 entities.

Zenodo link: https://doi.org/10.5281/zenodo.14900544

CPL-Article

CPL-Article is an annotated corpus describing bioinformatics tool names in English publications about bioinformatics workflows. This corpus is composed of 50 articles related to Nextflow workflows randomly selected from PubMed Central with a total of 76,002 tokens and 1,523 annotated tokens corresponding to 1,455 tool occurrences (425 unique tools).

Zenodo link: https://doi.org/10.5281/zenodo.20746904

CPL-Code

CPL-Code is an annotated corpus describing bioinformatics tool names in executable code of Nextflow workflows. This corpus comprises 1,368 Nextflow workflow processes, randomly selected from GitHub, totaling 137,337 tokens and 3,401 annotated tokens, corresponding to 3,398 tool occurrences (537 unique tools).

Zenodo link: https://doi.org/10.5281/zenodo.20746970

CPL-Gold-Entity-Resolution

CPL-Gold-Entity-Resolution is an annotated entity resolution corpus between publications and executable code for Nextflow workflows. This corpus comprises 39 workflows extracted from CPL-Article and CPL-Code. Bioinformatics tool mentions were extracted from both corpora, and cross-modal correspondences between tools were manually annotated, including unlinked cases. 490 cross-model links are represented.

Zenodo link: https://doi.org/10.5281/zenodo.20746994
